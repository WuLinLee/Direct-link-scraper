# Direct-link-scraper

一个用于**读取当前 Paste 页面中已存在的 FuckingFast 分享链接**，并请求对应服务解析结果的浏览器用户脚本。界面为中文，支持并发处理、文件名筛选、勾选、复制和 TXT 导出。

> **重要：本项目不是下载内容的授权证明，也不保证目标页面或文件的合法性。** 请先确认你有权访问、下载和使用相关内容，再运行脚本。

## 功能范围

- 仅匹配 `https://paste.fitgirl-repacks.site/*` 页面。
- 从页面 `#plaintext` 区域读取指向 `fuckingfast.co` 的分享链接。
- 通过 `fuckingfast.co` 的解析接口取得服务端返回的 HTTPS 跳转地址。
- 支持并发数设置、失败项重试、取消、文件名筛选、选择性复制和 TXT 导出。
- 批量复制、自动复制和 TXT 导出时，每条记录依次按“横线 → 文件名 → 横线 → 直链 → 横线”排列，便于区分文件。
- 另提供单条复制：显示当前文件名，可用上下箭头切换上一条/下一条，复制按钮只复制当前这一条直链。
- 不提供文件托管、文件搜索或内容分发服务。

本脚本依赖目标网站当前的页面结构和接口行为。第三方网站可能随时调整页面、接口或服务条款，功能因此可能失效。

## 安装

1. 在浏览器中安装支持用户脚本的管理器，例如 Tampermonkey 或 Violentmonkey。
2. 打开本仓库中的 [direct-link-scraper.user.js](./direct-link-scraper.user.js)。
3. 将脚本内容导入用户脚本管理器，并检查脚本权限后再启用。
4. 访问脚本匹配范围内的页面；页面加载后，右下角会出现“直链提取工具”。

脚本需要用户脚本管理器提供的 `GM_xmlhttpRequest` 权限，以便向 `fuckingfast.co` 发出解析请求。请不要从不可信来源安装修改版脚本。

## 使用说明

1. 打开受支持的 Paste 页面，等待页面正文加载完成。
2. 点击“开始提取”。
3. 根据需要调整并发数。默认值为 4；数值越高，请求越集中，建议谨慎调整。
4. 在“列表”视图中选择需要处理的项目；可按文件名筛选。
5. **批量复制：** 点击“批量复制已选”，复制内容包含文件名、直链及横线分隔符；也可以导出为 TXT。
6. **单条复制：** 在“单条复制”区域查看当前文件名，点击旁边的上/下箭头切换链接，再点击“复制当前直链”。此操作只复制当前这一条的纯直链 URL，不附带文件名或分隔横线。
7. 失败的项目可点击“重试失败项”；处理中可点击“取消”。

请注意：解析得到的地址是第三方服务返回的链接。打开前请自行核对域名、文件名、文件来源和授权情况。

## 隐私与网络请求

- 脚本在当前浏览器页面中运行，不会将页面正文上传到本项目维护者的服务器。
- 解析时，脚本会向 `fuckingfast.co` 发送请求；请求中包含从分享链接路径提取的标识符。
- 复制操作使用浏览器剪贴板；TXT 导出由浏览器本地生成。
- 本项目本身不设置账号系统、统计服务或自有后端。浏览器、用户脚本管理器及第三方网站仍可能按各自政策处理网络请求数据。

## 故障排查

- **没有找到链接：** 确认当前页面属于匹配域名，并且正文已加载；脚本只读取 `#plaintext a[href]` 中符合条件的链接。
- **部分解析失败：** 可点击“重试失败项”。如果第三方服务变更接口或暂时不可用，重试也可能失败。
- **请求被拦截：** 检查用户脚本管理器是否允许 `GM_xmlhttpRequest`，以及是否允许连接 `fuckingfast.co`。
- **功能突然失效：** 目标网站的页面结构和接口不受本项目控制；请先确认第三方服务是否变更。
